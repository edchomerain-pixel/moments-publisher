# Telegram 回图、本机手动添加流程（2026-10-27）

用户已取消云端收件箱和自动同步。当前目标：发送截图到原 CleanPic 机器人 → 裁剪与文字分流 → 普通图片通过原 Telegram 账号直接回传 → 用户保存到 iPhone，再手动添加到巴商相册。

## 相册变更

- 主入口移除云端连接、收件箱及 AutoSync；打包产物不再载入云端客户端。
- 只移除本机旧的 bashang:inbox-connection:v1 凭据，不清除其他网站存储，不删除照片、文案或记录。
- 数据库保持 version 2 和原 drafts/dismissed 表，避免降级无法打开；已经导入的云图仍为普通本机记录。
- 保留手动添加图片、编辑、排序、搜索、复制、分享和ZIP导出。旧云端服务、凭据和对象不删除。

## 本机处理变更

- 自动化配置改为 delivery=telegram；原精确白名单及 enabled:true 保留。
- 当前Telegram入口要求显式telegram输出配置，不使用云端上传器或读取云端密钥。通过现有OpenClaw message send及原账号发送，不增加Bot API轮询器。
- 回传任务单独存放 automation/telegram-return，旧云端任务和回执完整保留，不混用去重记录。
- 原图、裁剪候选和待修复任务持续保留。文字筛查为保守OCR，不能保证识别所有水印；待修复图不冒充处理成功图发送。
- 每张回传均记录Telegram确认的消息编号。发送前落盘delivery_pending；超时、退出或缺少可靠确认记作delivery_uncertain，重跑不会盲目再次发送。不能承诺网络边界上的绝对恰好一次。
- 默认按照片发送，便于手机保存；Telegram可能压缩图片，本机PNG候选仍保留原始输出字节。
